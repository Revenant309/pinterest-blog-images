# Pinterest Image Guidelines for Blog Posts

## Recommended Specs
- **Aspect ratio**: 2:3 (portrait) — ideal for Pinterest feed
- **Orientation**: Always use `portrait` when generating with Imagine
- **Style**: High visual impact, bright, clean, lifestyle or illustrative. Avoid cluttered or text-heavy designs unless the text is short and bold.
- **Quantity**: Generate 3–6 images per blog post covering different angles.

## Image Types to Create
| Type | Purpose | Prompt focus |
|------|---------|--------------|
| Cover / Hero | Main pin linking to the post | Bold title concept, emotional hook, lifestyle scene |
| Tip / List | Carousel-style or single tip | Numbered tip, clean layout, readable text overlay idea |
| Quote | Shareable quote from the post | Short quote + author/brand aesthetic |
| Step-by-step | Process visualization | 1–2 key steps illustrated simply |
| Before/After or Problem/Solution | Engagement | Contrast visual |
| Infographic-style | Data or summary | Clean icons, limited text |

## Prompt Best Practices
- Always specify: "Pinterest pin style, vertical 2:3 aspect ratio, high quality, vibrant colors, professional photography or modern illustration"
- Include short text overlay suggestion in the prompt when useful (e.g., "with bold text overlay: '5 Tips for...'")
- Keep prompts concrete and visual. Avoid abstract concepts without visual anchors.
- Vary styles across the set: one photographic, one illustrated, one minimalist, etc.

## Pinterest Caption Structure
For each image provide:
1. Short title (≤100 chars)
2. Description (2–3 sentences + relevant keywords)
3. Suggested hashtags (5–8)
4. Call-to-action (e.g., "Read the full guide → [link]")

## Workflow Notes
- Extract 4–6 distinct visual ideas from the blog post before generating.
- Prioritize the strongest hook, a practical tip, and a quote when available.
- After generating, present images with their captions ready to copy-paste.
